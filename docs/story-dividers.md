# Story guide dividers

In edit mode, choose **Add subsection → Content Template → Divider**, choose a navigation category, then create it. Dividers have a stable internal ID and order, with no title to enter.

Reading mode shows a minimal ornament between fading horizontal lines. Its color follows the game's highlight. Edit mode adds the usual drag handle and edit/delete actions; keyboard reordering uses the same Up/Down controls as other subsections.

Dividers are decorative. They are excluded from completion totals, subsection counts, search, navigation directories and resume locations, and are hidden by Show incomplete only. They persist in the existing story catalog with category `divider` and an empty name. Other content still requires a title. No migration or deletion of existing database content is needed.
